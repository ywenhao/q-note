# Q Note 功能规格

本文档是 Q Note 当前功能、交互、视觉和数据行为的事实基线，供日常调整、回归检查以及更换框架或编程语言时使用。

本文档只描述“产品应该做什么”，不记录源码文件、模块、类、接口、依赖或框架实现方式。功能或交互细节发生变化时，直接更新对应条目，使本文档始终反映当前有效行为。

配套的 [TEST_CASES.md](./TEST_CASES.md) 把这些规则展开为固定编号、测试数据、步骤和断言。本文定义产品规则，测试目录负责验证规则；存在旧实现缺陷时仍以规则为验收目标，不能把源码检查或尚未执行的用例记为通过。

## 1. 产品定位

- Q Note 是一个轻量、紧凑、靠近鼠标使用的桌面便签板。
- 核心使用场景是快速保存和反复复制短文本、截图、图片地址、本地路径及参考资料。
- 主面板适合窄尺寸常驻，也允许放大以浏览更多内容。
- 重要便签可以置顶，便签可以改色、排序和调整文字显示高度。
- 不需要占用屏幕时，主面板可以收成 30px 悬浮球。
- 应用支持中文和英文，两种语言下的功能与信息层级必须一致。

## 2. 全局行为原则

- 用户便签和设置必须持久保存，正常升级、重启、隐藏窗口或切换悬浮球时不得丢失。
- 主窗口关闭后应用继续驻留托盘；只有明确执行“退出”才结束进程。
- 窗口置顶是全局设置，主窗口、编辑窗口和悬浮球同步生效。
- 所有会删除大量数据、替换全部数据或安装更新的操作，都必须给出清晰反馈或确认。
- 控件点击不得穿透到下层操作。例如点击卡片操作按钮时，不能同时触发卡片复制。
- hover 控件在按下到抬起期间必须保持可操作，不能因 hover 状态瞬间丢失而取消点击。
- 网络图片加载不能阻塞窗口交互；加载失败时保留便签和附件数据，不影响其他内容使用。
- 在不支持窗口定位、贴边或原生裁剪的平台上，应安全降级，不得因此导致应用无法启动或数据丢失。
- 下文组件尺寸以设计像素描述。原生屏幕坐标、逻辑坐标和物理像素必须显式换算，不能把系统缩放重复应用。持久化窗口数据采用物理像素；主分支 Windows/Linux 的窗口限制按物理尺寸执行，macOS 窗口限制按逻辑尺寸执行。截图验收必须记录平台、DPI 和尺寸单位。

### 2.1 默认值与共享菜单

- 初始便签正文为空、附件为空、不置顶，颜色为 `#fff9db`；保存空正文且没有附件不产生记录。
- 系统语言以不区分大小写的 `zh` 开头时默认中文，否则默认英文；已保存的合法语言优先。
- 默认关闭全局置顶、开机启动、贴边设置和悬浮球会话；默认无吸附边缘、无保存窗口几何数据。
- 托盘与悬浮球共享菜单规则：置顶/取消置顶、切换语言、切换主面板/悬浮球、分隔线、退出。状态文案必须反映当前状态。卡片右键菜单是另一组操作，不能与共享菜单混用。
- 普通数据写入失败时不提交新的可见内容；用户能重试同一操作。失败不得用成功提示覆盖，也不得清空原始数据。

## 3. 启动与主窗口

### 3.1 启动

- 每次启动都先显示完整主面板，不恢复上次进程遗留的悬浮球状态。
- 启动时使用已保存的主窗口尺寸。
- 主窗口初始位置位于主屏右侧约 40px，并垂直居中。
- 已保存尺寸超出允许范围时，自动限制到合法范围。
- 开机启动的显示效果与普通启动一致。
- 如果上次更新前保存了未完成编辑草稿，启动主面板后自动恢复对应编辑窗口。
- 设置 JSON 无法解析时，按默认设置处理；已有便签不得因此被删除或阻止启动。
- 便签或设置完全无法读取时，不得停留在启动加载画面。应使用空便签列表和默认设置显示主面板，并显示加载失败提示约 1.7 秒。

验收场景：

- 设置值被改成非法 JSON 后启动，主面板必须出现。已有便签仍显示；语言、置顶、开机启动和窗口状态使用默认值。
- 数据库完全无法打开时，主面板必须出现并显示空列表和约 1.7 秒的加载失败提示，不得无限停留在启动加载画面。

### 3.2 窗口尺寸与移动

- 主窗口默认及最小尺寸为 `300×450`。
- 主窗口最大尺寸为 `1000×800`。
- 主窗口可拖动、可调整大小，不提供最大化入口。
- 窗口位置或尺寸变化后约 300ms 保存一次，避免移动过程中频繁写入。
- 窗口恢复时必须落在可见显示器区域内，不能完全出现在屏幕外。
- 多显示器和不同 DPI 下，尺寸、位置和工作区限制保持正确。

### 3.3 自绘标题栏

- 主面板和编辑窗口各只有一套自绘标题栏和一组窗口按钮；系统标题栏、系统标题按钮不得叠加，原生外框尺寸与内容区尺寸相等。
- 标题栏包含 Q 标识、应用标题、置顶、最小化和关闭按钮。
- 主窗口标题区高 24px，Q 标识 22px；编辑标题只显示文字，不重复 Q 标识，标题下内边距 4px。标题字号 15.12px、字重 600。
- 窗口按钮胶囊：内边距 2px、间距 2px、圆角 12px、1px 白色 42% 描边、白色 26% 背景；置顶、最小化、关闭按钮各 18×18px，图标 10px。
- 标题文字区域可拖动窗口。
- 置顶按钮显示当前状态，并同步修改所有窗口。
- 最小化按钮最小化当前窗口。
- 关闭按钮和系统关闭事件仅隐藏主面板，不退出应用。
- 核心图标必须稳定显示，不能因系统字体缺字而显示为方框。

## 4. 主工具栏与状态区

- 主面板内边距为上 8px、左右 10px、下 28px，内容列最大宽度 980px、水平居中。
- 标题下留 4px；工具栏内边距 3px、圆角 8px、间距 4px、下边距 7px；从左到右为新建、全部删除、设置、目标语言，空间不足允许换行。
- 工具栏按钮高 26px，图标按钮宽 26px、图标 13px，白色 46% 背景；新建保持紧凑图标按钮。
- “新建”打开独立编辑窗口。
- “全部删除”在没有便签时不可用。
- 点击“全部删除”先显示不可撤销确认弹层，确认后才删除全部便签和附件。
- “设置”打开设置弹层。
- 检测到新版本时，设置入口显示红点；提示信息包含可用版本。
- 语言入口显示将切换到的目标语言，点击后立即刷新主窗、编辑窗、悬浮球和托盘菜单。
- 主面板底部显示当前便签总数。
- 计数在距底部 7px 的位置水平居中、字号 12px；Q 按钮 28×28px、距右 14px、距底 22px，内部 Q 标识 18px。
- 右下角 Q 按钮把主面板切换为悬浮球。
- 没有便签时显示 Q 标识、空状态说明和新建入口。

## 5. 便签排序与显示

### 5.1 排序

- 置顶便签始终排在普通便签之前。
- 每个分组内部优先采用用户手动排序；顺序相同时，最近更新的便签优先。
- 新便签放到对应置顶分组或普通分组的顶部。
- 修改置顶状态后，便签移动到目标分组顶部。
- 拖动便签可以调整顺序。
- 将便签拖到另一分组的目标便签旁时，便签同时采用目标分组的置顶状态。
- 拖动后的置顶状态和完整顺序必须持久保存。
- 排序写入失败时，卡片顺序和置顶状态保持写入前的显示，并显示保存失败提示约 1.7 秒。

### 5.2 卡片内容

- 卡片使用便签选择的颜色。
- 置顶便签显示置顶标记，并使用更明确的选中描边。
- 有正文时显示正文。
- 正文为空但包含图片时，显示本地化的“图片便签”占位文案。
- 卡片没有独立的固定默认高度或最小外框高度；外框高度始终由当前可见文字和附件内容计算，不能为了统一卡片高度而在短内容下方保留空白。
- 默认文字高度等于当前卡片宽度下实际换行数与 2 的较小值，再乘以 22px 行高：实际只需一行时显示一行，实际需要两行或更多时默认显示两行。
- 无附件时，卡片外框高度为 `10px 上内边距 + 可见文字高度 + 9px 下内边距`。因此一行纯文本卡片高 41px，两行纯文本卡片高 63px；手动展开到 N 行时高度为 `19 + 22×N` px。
- 图片区、文件区与前一个可见内容区之间各有 8px 垂直间距；图片区高 58px；每个文件条目高 30px，同一文件区内相邻条目间距为 6px。附件出现或移除时，卡片外框按这些内容尺寸同步增减。
- 主窗口宽度变化后立即按新的可用文字宽度重新计算换行数、默认文字高度和卡片外框高度；从两行变成一行时，纯文本卡片必须同步从 63px 收回到 41px。
- 卡片底部提供文字高度调整手柄，按 22px 行高逐行调整。
- 最小文字高度等于当前宽度下的默认显示高度，最大文字高度等于完整正文在当前宽度下的实际总行高；拖动过程中不得越过这两个边界。
- 用户调整后的文字高度必须持久保存。
- 卡片最多直接展示 4 张图片缩略图和 3 个文件条目；未展示的附件仍完整保留。

验收场景：

- 新建一条在当前宽度下不会换行、且没有附件的便签，卡片外框必须为 41px 高，文字下方不得出现由固定默认高度造成的额外空白。
- 新建一条在当前宽度下需要两行或更多行的纯文本便签，默认只显示两行且卡片外框为 63px 高；超过当前可见行数的正文在末尾显示 `...`。
- 调宽主窗口直到同一条正文由两行变成一行，卡片外框必须同步由 63px 变为 41px；调窄后重新按实际换行数恢复一行或两行默认高度。
- 将文字高度手动展开到完整内容高度后重启应用，展开行数应恢复；若改变窗口宽度使完整正文所需行数减少，恢复高度必须限制到新的完整内容高度，不能留下空白行。

### 5.3 点击复制

- 点击卡片主体复制便签内容。
- 正文非空时复制正文。
- 正文为空时，按附件顺序复制所有附件值，并使用换行连接。
- 复制成功后显示约 1.7 秒的提示。
- 图片缩略图、文件区域、操作按钮、颜色选择器、拖动和高度调整不能触发卡片复制。
- 拖动或调整高度结束后的短时间内抑制误触复制。
- 排序结束后 400ms、文字高度调整结束后 300ms 内不响应附带的主体复制；之后新的独立点击恢复复制。附件和控件触发的事件不能在延迟后补发复制。

### 5.4 卡片操作

- 鼠标悬停卡片时显示操作条。
- 右侧入口距卡片右边 2px、垂直居中，为 20px 圆形左箭头；展开后箭头仍在最右，按钮区在箭头左侧 22px，不能迁移成卡片顶部固定工具栏。
- 按钮区内边距 4px、间距 5px、圆角 12px、白色 86% 背景，按钮各 24×24px；约 150ms 从右侧 6px 淡入，关闭反向淡出。鼠标离开后的关闭延迟为 150ms。
- 操作条包含：置顶/取消置顶、编辑、改色、复制、删除。
- 鼠标离开操作条时可短暂延迟关闭，保证点击按下和抬起能够完整发生。
- 改色显示 12 色选择器，当前颜色有明确选中状态。
- 点击颜色选择器外部关闭选择器。
- 色板在改色按钮下方锚定，为 4 列、3 行，色块直径 20px、间距 5px、内边距 6px、圆角 8px，当前颜色有对勾。色板打开时保留所属操作条；在边缘自动避让，不被其他卡片遮挡。
- 删除单条便签立即删除该便签及其附件，不额外弹出确认。
- 单条删除或全部删除写入失败时，被删内容仍保持写入前的显示，并显示删除失败提示约 1.7 秒。
- 改色、置顶或文字高度写入失败时，卡片保持写入前的显示，并显示保存失败提示约 1.7 秒。
- 右键菜单包含：复制、编辑、置顶/取消置顶、删除。
- 操作条和右键菜单中的同名操作必须具有相同行为。
- 仅卡片区域右击打开卡片菜单，主面板空白处不显示卡片菜单。应用内菜单与内容区边界保留 8px；某轴连菜单与两侧留白也容纳不下时，该轴从 0 开始，不允许负坐标。

## 6. 独立编辑窗口

### 6.1 窗口行为

- 新建和编辑便签均使用独立窗口，不改变主面板尺寸。
- 编辑窗口默认尺寸为 `520×640`，最小尺寸为 `420×520`。
- 编辑窗口最大尺寸为 `1000×800`。
- 编辑窗口默认位于主面板左侧约 12px，并垂直居中。
- 空间不足时，编辑窗口自动限制在当前显示器工作区内。
- 同时只保留一个编辑窗口。
- 已有编辑窗口时再次新建或编辑，会结束旧编辑会话并打开新目标。
- 处于悬浮球模式时发起编辑，先恢复完整主面板。
- 窗口标题根据“新建/编辑”和当前语言实时变化。
- 标题栏支持拖动、全局置顶、最小化和关闭。

### 6.2 正文与颜色

- 顶部显示完整 12 色便签色板。
- 编辑窗口内边距为上 8px、左右 10px、下 12px，主体背景 `#fff9df`，内容区间距 12px。色板靠左，内边距上 8px、左右 12px；色块直径 20px、间距 7px，可换行；选中项有深色描边和 3px 浅色外环。
- 当前颜色有明显的选中描边。
- 正文为多行输入，空内容时显示本地化占位文案。
- 正文区平直铺满可用宽度，不跟随便签颜色、不使用圆角；背景白色 50%，上下 1px 分隔线，内边距上下 14px、左右 16px，字号 14px、行高 21.7px，最小高 140px，其余可用高度分给正文；聚焦不出现蓝色外框。
- 正文、颜色和置顶状态变化后，同步更新当前未完成草稿。
- 保存时移除正文首尾空白，正文内部格式保持不变。

### 6.3 添加附件

- “图片”入口允许一次选择多张图片。
- 支持 PNG、JPG/JPEG、GIF、WebP、BMP 和 SVG。
- 通过图片选择器加入的图片以内嵌数据保存，原文件移动后仍可使用。
- 可以输入网络图片 URL、本地图片路径或普通文件路径。
- 按 Enter 或点击“添加”加入输入值。
- `http://` 和 `https://` 识别为网络来源，`data:` 识别为内嵌数据，其他值识别为本地路径。
- 常见图片扩展名和图片 data URL 识别为图片，其他值识别为文件。
- URL 中的查询参数或片段不影响图片扩展名识别。
- 路径判定的图片扩展名为 `avif`、`bmp`、`gif`、`jpeg`、`jpg`、`png`、`svg`、`webp`，不区分大小写；手动输入去掉首尾空白，空输入不添加。一次添加成功后清空输入，重复选择同一文件仍可再次添加。
- 可以将一个或多个本地文件拖入编辑窗口。
- 拖入时，图片路径添加为图片附件，其他路径添加为文件附件。
- 正文输入处于焦点时粘贴剪贴板图片，会将图片添加为内嵌 PNG 附件。
- 剪贴板没有图片时，不拦截普通文本粘贴。
- 网页拖入同时包含多种表示时，优先采用图片 URL，其次普通 URL，最后读取文件对象为内嵌数据；同次拖入的重复 URL 去重。来自本地系统文件拖放的真实路径不替换为临时 URL。

### 6.4 附件管理

- 图片附件显示缩略图，点击缩略图打开图片预览。
- 图片缩略图提供删除入口。
- 文件附件显示文件名；没有可用文件名时显示完整附件值。
- 文件附件提供删除入口。
- 附件较多时，附件区域可以滚动，不挤压保存操作区。
- 删除编辑中的附件只影响当前草稿，保存后才写入便签。
- 同名附件按各自标识区分，删除一个不得误删其他同名项；附件顺序在保存、重启、导出再导入后保持。

### 6.5 保存与取消

- “置顶”选项切换当前草稿的置顶状态。
- 底部左侧为 16×16px 方形置顶复选框，右侧依次取消、保存，间距 8px、高 28px；取消为浅色描边、保存为深色底白字。
- 保存空正文且没有附件时，按取消处理，不创建空便签。
- 保存新便签时生成新记录并放入正确分组。
- 编辑已有便签时保留原创建时间，更新内容、附件、颜色、置顶状态和更新时间。
- 保存成功后关闭编辑窗口、刷新主面板并显示成功提示。
- 保存失败时保留编辑窗口和当前内容，并显示失败提示约 1.7 秒；主面板在保存成功前不替换对应卡片。
- 取消、关闭按钮或系统关闭事件会丢弃当前普通编辑会话，不弹出未保存确认。
- 取消或成功保存后清除对应草稿恢复记录。
- 安装更新前，如果编辑窗口存在未完成修改，保存恢复草稿；更新重启后自动重新打开。

## 7. 图片预览

- 主面板和编辑窗口使用一致的图片预览行为。
- 预览覆盖当前窗口内容并使用深色遮罩。
- 点击遮罩、关闭按钮或按 Esc 关闭预览。
- 显示当前序号、图片总数和缩放百分比。
- 多图时左右按钮循环切换图片。
- 未放大时，左/右方向键切换图片。
- `[`、PageUp 切换上一张；`]`、PageDown 切换下一张。
- 切换图片后重置为 100% 缩放和居中位置。
- 缩放范围为 50%–600%，每次调整 25%。
- 鼠标滚轮、`+`、`-` 和缩放按钮均可调整缩放。
- `0`、重置按钮或双击图片恢复 100% 和居中位置。
- 放大后可以拖动图片平移。
- 放大后方向键用于平移；左/右方向键不再切换图片。
- `=` 与 `+` 等价；滚轮向上增加 25%、向下减少 25%，到边界后不越界。50%–100% 时位置居中且不可拖拽平移。
- 放大后方向键每次平移 36px：左/上将图像分别向右/下移动，右/下反向。设显示图片宽高为 W/H、舞台宽高为 S/T、缩放为 z，横向边界为 `±(max((W×z-S)/2,0)+80)`，纵向同理；改变图片或重置后偏移归零。
- 仅鼠标左键可发起平移，离开原图区域后仍跟踪同次按下，抬起或取消后立即停止。单图不显示切图按钮；多图首尾循环。
- 打开预览后由预览接收键盘；预览按钮、图片和切图入口不触发遮罩关闭或下层复制，关闭后原编辑内容不变。
- 预览舞台内边距为上 54px、左右 44px、下 42px；图片按比例容纳，最大宽为 `min(1120px,窗口宽-88px)`、最大高为 `窗口高-108px`、圆角 8px；工具条距顶和右各 12px，按钮 28×28px。

## 8. 设置

- 设置以居中弹层显示。
- 面板宽为 `min(276px,窗口宽-32px)`，内边距 8px、内容间距 7px、圆角 10px；遮罩覆盖整个内容区。导入和导出并列在同一行。
- 设置标题保持水平居中，关闭按钮固定在面板右上角。
- 点击遮罩或关闭按钮关闭设置。
- Esc 关闭设置；面板内部按下或切换开关不关闭设置，关闭不触发背景卡片动作。
- 点击设置面板内部空白或控件不能误关闭弹层。
- 设置包含：开机启动、导入、导出、检查更新和当前版本。
- 开机启动开关显示当前系统真实状态，而不只依赖上次保存值。
- 修改开机启动后显示成功或失败提示。
- 语言、置顶和开机启动写入成功后才更新对应界面状态；写入失败时界面保持原值。
- 窗口置顶必须先写入成功，再同步到主窗口、编辑窗口和悬浮球；写入失败时所有窗口保持原来的置顶状态，并显示保存失败提示约 1.7 秒。
- 当前版本可以点击并打开对应版本发布页。
- 有可用更新时，检查更新入口显示红点和提示。

## 9. 导入与导出

### 9.1 导出

- 导出默认文件名为 `q-note_yyyyMMddHHmm.json`。
- 导出内容包含格式版本、导出时间、全部便签、附件和设置。
- 取消保存文件选择时不显示成功提示，也不修改任何数据。
- 导出成功后显示完成提示。

### 9.2 导入

- 导入支持当前格式，也兼容缺少新字段的旧数据。
- 缺失字段使用安全默认值；无效单条便签或附件不会阻止其他有效内容导入。
- 导入会整体替换当前便签和设置，这是唯一允许主动整体替换用户数据的流程。
- 取消文件选择时不修改数据。
- 解析或读取失败时保留原数据并显示失败提示。
- 解析成功但写入替换失败时，磁盘和界面都保持导入前的数据，并显示导入失败提示。
- 导入替换必须一次性生效：中途失败不得留下空库或半导入结果。
- 导入成功后立即刷新便签、排序、语言、窗口置顶、开机启动和托盘标签。

验收场景：

- 选择非法 JSON 或取消文件选择时，便签和设置保持不变，取消时不显示成功或失败提示。
- 文件可解析但写入替换中途失败时，原便签和设置仍在，界面不切换到导入内容，并显示导入失败提示。
- 合法文件导入成功后，主面板立即显示导入的便签和设置；再次启动后内容保持导入结果。

## 10. 更新

- 应用启动后静默检查一次更新。
- `main` 使用正式 `v*` 发布通道；当前平台不支持的包只提供对应发布页，不把其他发布系列作为本通道可安装更新。
- 此后每天本地时间 17:00 再检查一次。
- 静默检查没有更新或失败时不打扰用户。
- 手动检查没有更新时显示“暂无更新”；失败时显示失败提示。
- 静默发现新版本只更新可用版本状态和红点；用户手动检查或选择已有更新后显示确认，内容包括版本、默认更新说明和可选发布说明。取消确认不下载安装。
- 同一时刻只允许一次检查及一次下载/安装；检查期间入口不可重复触发，日程只注册一次。当天已到或过 17:00 时，下次定时检查为次日 17:00。
- 当前平台没有可安装程序时，打开对应版本发布页并提示用户手动下载。
- 自动安装前验证下载地址、文件格式、声明大小和 SHA-256 信息是否有效。
- 下载过程显示当前阶段、版本、发布说明、百分比和已下载/总大小。
- 已知总大小按累计字节计算百分比并限制在 0–100%；未知大小显示累计字节、不伪造总量，完成前不显示已完成，完成后为 100%。负的增量不减少已下载字节。准备与安装阶段显示不确定进度和各自状态。
- 下载和准备阶段允许取消；进入安装阶段后不允许取消。
- 下载过程中持续检查取消状态。
- 下载结束后验证实际大小和 SHA-256；验证失败不得安装。
- 安装前保存主窗口状态、设置和未完成编辑草稿，并确保数据落盘。
- 编辑窗口的安装准备确认最长等待 5000ms；明确失败或超时不能忽略后继续安装，必须反馈准备失败，原窗口和草稿继续可用。
- 安装成功后启动新版本并退出当前进程。
- 下载、准备或安装失败时清理更新状态、保留用户数据并显示对应提示。

## 11. 系统托盘

- 应用运行期间托盘图标常驻。
- 左键点击托盘图标显示并激活主面板。
- 处于悬浮球模式时，左键点击托盘先退出悬浮球模式再显示主面板。
- 托盘菜单包含：窗口置顶/取消置顶、切换语言、切换主面板/悬浮球、退出。
- 菜单文字根据当前语言、置顶状态和悬浮球状态实时变化。
- 点击“退出”前保存窗口状态、设置和编辑草稿，并确保便签数据落盘。

## 12. 30px 悬浮球与贴边

### 12.1 切换与恢复

- 主面板右下角 Q 按钮和托盘菜单均可切换到悬浮球。
- 悬浮球尺寸固定为 `30×30`，背景透明、无原生边框，内部显示 Q 标识。
- 悬浮球出现时使用约 180ms 的淡入动画。
- 切换时保存主窗口尺寸和位置并隐藏主窗口，尽量保留原窗口实例和界面状态。
- 悬浮球在当前可用工作区内以目标坐标打开，完成首次显示和淡入后再隐藏主面板。切换完成时球必须立即可见并位于当前窗口层级前方，不得等待点击托盘或打开右键菜单才出现。
- 单击悬浮球恢复原主面板并激活窗口。
- 拖动距离未超过 4px 时按点击处理；超过 4px 后按移动处理，不触发恢复。
- 悬浮球右键菜单包含：置顶/取消置顶、切换语言、恢复主界面、退出。
- 悬浮球右键菜单与系统托盘右键菜单使用相同的项目、顺序、状态文字和分隔方式。
- 原生悬浮球菜单紧邻鼠标右击位置，只有工作区不足时向内避让；菜单打开期间不恢复主面板、不拖动、不半隐藏。

验收场景：

- 从主面板 Q 按钮及托盘菜单分别切换到悬浮球，不再操作托盘，确认 30×30 的 Q 标识在工作区内出现，主面板随后隐藏。托盘右键菜单打开、关闭前后，球的可见性和位置保持不变。
- 连续三次切换、点击球恢复，主面板尺寸和内容保持，球每次均可见；切换的首次显示或淡入期间恢复主面板后，旧的回调不得再次隐藏主面板或显示已关闭的球。

### 12.2 拖动与吸附

- 悬浮球可以拖到当前显示器工作区内任意位置。
- 距离工作区左、右、上、下边缘 28px 内释放时，吸附到最近边缘。
- 未达到吸附阈值时，停留在工作区内的释放位置。
- 吸附状态记录边缘和沿边位置。
- 多显示器环境按悬浮球当前所在显示器计算工作区。
- Windows 上使用任务栏工作区，并正确处理 DPI 和相邻显示器裁剪。
- 未触及边界时悬浮球的屏幕位移与鼠标屏幕位移一致，按下点相对球的位置保持；不能混用窗口内、屏幕或物理/逻辑坐标，不能在持续同向移动时反向抖动。拖动中不运行贴边动画，窗口外松开或取消也会结束拖动且不触发恢复。
- 吸附距离包含 28px 边界，超过 28px 不吸附；同距边缘按左、右、上、下顺序决定。

### 12.3 半隐藏与悬停

- 吸附后使用约 130ms 动画向屏幕外移动一半，只保留半圆可见。
- 鼠标进入可见半圆时，悬浮球完整滑出。
- 鼠标离开完整悬浮球后，再次半隐藏。
- 拖动开始前取消正在进行的隐藏或显示动画，并恢复完整可拖区域。
- 从贴边悬浮球恢复主面板后，记录原边缘和位置 5 分钟。
- 5 分钟内再次收起时回到原边缘和位置，并等待约 500ms 后再半隐藏，避免刚出现就从鼠标下移走。
- 位置缓存到 5 分钟整仍有效，超过后过期；缓存显示器已移除时限制到当前工作区，不把窗口留在屏幕外。动画可中断、反向或重入，最终状态服从最后一次有效操作，不振荡。

## 13. 反馈、语言与错误状态

- 中文和英文必须覆盖同一组功能、按钮、菜单、标题、占位文案和错误提示。
- 切换语言后无需重启，所有已打开窗口和托盘菜单立即刷新。
- 复制、保存、导入、导出、开机启动、加载失败、删除失败和更新相关结果使用短暂提示反馈。
- 普通成功提示约显示 1.7 秒。
- 危险操作使用红色语义；主要确认操作使用统一主按钮语义。
- 禁用、悬停、按下、选中和错误状态必须视觉可区分。
- 弹层、图片预览、颜色选择器和操作条的层级必须正确，不能被后续卡片或底层控件遮挡。
- 设置、删除确认、更新确认、更新进度、颜色选择器、toast 和图片预览等应用内弹层，打开时统一淡入并轻微上移，关闭时反向淡出，动画时长约 140–160ms。

## 14. 数据与兼容性

- 用户数据位于用户主目录下的 `.q-note/q-note.db`。
- Windows 路径为 `C:\Users\<username>\.q-note\q-note.db`；macOS/Linux 为 `~/.q-note/q-note.db`。
- 新数据文件尚不存在时，启动过程必须先从旧安装位置复制数据库，然后再打开或创建新位置的数据库。不得先创建空的新数据库再检查旧文件，否则复制不会发生。
- Windows 旧位置为 `%APPDATA%\com.win11.q-note\q-note.db`。若该文件存在且新文件尚不存在，复制到 `C:\Users\<username>\.q-note\q-note.db`，不删除旧文件。
- 新文件已经存在时（即使尚未写入便签）不得用旧文件覆盖。
- 必须保留便签正文、颜色、置顶状态、手动顺序、文字高度、附件类型、附件来源、附件值、附件名称和创建/更新时间。
- 必须保留语言、全局置顶、开机启动、窗口尺寸/位置和悬浮球相关设置。
- 启动时主动清理上次异常遗留的悬浮球会话状态，但不删除其他设置。
- 除明确执行单条删除、全部删除或整体导入替换外，不得主动删除用户数据。
- 更换框架或语言时，现有数据库和导入导出数据必须继续可读写，不能要求用户手工迁移。
- 旧数据库有尚未合并的日志数据时，迁移也必须保留其中已提交的便签；迁移完成后源文件仍可读。旧结构升级只补全字段和默认值，不重建空数据覆盖原内容。

### 14.1 公开导入导出契约

- 导出根字段为 `version: 1`、ISO 8601 字符串 `exportedAt`、`notes` 数组和 `settings` 对象。
- 每条便签保留 `id`、`content`、`color`、`pinned`、`sortOrder`、`textHeight`（未手调时为 null）、`attachments`、`createdAt`、`updatedAt`；时间为毫秒时间戳。
- 每个附件保留 `id`、`kind`（image/file）、`source`（url/path/data）、`value`、可选 `name`、`createdAt`。内嵌值完整保留字节，网络值和路径不因导出而下载或改写。
- 设置字段为 `language`、`alwaysOnTop`、`autoStart`、`dockOnEdge`、`docked`、`dockEdge`、`keepFullMain`、`window`；window 为 null 或物理像素的 width/height/x/y。
- 旧文件缺少 notes 或不是数组时使用空列表；非对象便签被略过；便签缺少正文、颜色、置顶、附件、高度时分别用空串、默认颜色、false、空数组、null；缺少标识生成唯一新标识，缺少顺序按负更新时间放置，缺少有效时间时用导入时刻。
- 附件不是对象或 value 不是字符串时略过；缺少来源或来源无法识别时兼容为 url，合法 kind 优先保留，否则按来源和值识别种类；缺少名称允许不保存 name。
- 无效语言回退系统默认；无效吸附边缘为 null；无效窗口尺寸为 null，合法尺寸按物理值取整，缺少或无效坐标为 0。布尔设置兼容真值转换，dockOnEdge 只接受布尔值，其他类型回退 false。

### 14.2 更新草稿契约

- 可见编辑窗口相对原便签的正文、颜色、置顶或附件任一变化即为未完成修改；新建空白且未改变的窗口不产生恢复记录，隐藏或未修改的窗口也不产生记录。
- 恢复记录包含 draft（content/color/pinned/attachments）、noteId（已有记录标识或 null）、savedAt（毫秒）；附件为独立副本，后续编辑不能改写已保存恢复值。
- 恢复记录严格校验：正文/颜色为字符串、置顶为布尔、时间为有限数字、附件标识和值为字符串、种类和来源必须合法；任一附件非法则整条恢复记录无效。非法 JSON 或无效恢复记录不得阻止主面板启动。
- 恢复时原便签仍存在则进入该便签编辑；原便签已不存在或 noteId 为 null 则按新建草稿打开。恢复并不自动提交成正式便签；用户保存或取消后清除恢复记录。
