# Q Note 功能规格

本文档是 Q Note 当前功能、交互、视觉和数据行为的事实基线，供日常调整、回归检查以及更换框架或编程语言时使用。

本文档只描述“产品应该做什么”，不记录源码文件、模块、类、接口、依赖或框架实现方式。功能或交互细节发生变化时，直接更新对应条目，使本文档始终反映当前有效行为。

## 1. 产品定位

- Q Note 是一个轻量、紧凑、靠近鼠标使用的桌面便签板。
- 核心使用场景是快速保存和反复复制短文本、截图、图片地址、本地路径及参考资料。
- 主面板适合窄尺寸常驻，也允许放大以浏览更多内容。
- 重要便签可以置顶，便签可以改色、排序和调整文字显示高度。
- 不需要占用屏幕时，主面板可以收成 30px 悬浮球。
- 应用支持中文和英文，两种语言下的功能与信息层级必须一致。

## 2. 全局行为原则

- 用户便签和设置必须持久保存，正常升级、重启、隐藏窗口或切换悬浮球时不得丢失。
- 主窗口关闭后应用继续驻留托盘；只有明确执行“退出”才结束进程。
- 窗口置顶是全局设置，主窗口、编辑窗口和悬浮球同步生效。
- 所有会删除大量数据、替换全部数据或安装更新的操作，都必须给出清晰反馈或确认。
- 控件点击不得穿透到下层操作。例如点击卡片操作按钮时，不能同时触发卡片复制。
- hover 控件在按下到抬起期间必须保持可操作，不能因 hover 状态瞬间丢失而取消点击。
- 网络图片加载不能阻塞窗口交互；加载失败时保留便签和附件数据，不影响其他内容使用。
- 在不支持窗口定位、贴边或原生裁剪的平台上，应安全降级，不得因此导致应用无法启动或数据丢失。

## 3. 启动与主窗口

### 3.1 启动

- 每次启动都先显示完整主面板，不恢复上次进程遗留的悬浮球状态。
- 启动时使用已保存的主窗口尺寸。
- 主窗口初始位置位于主屏右侧约 40px，并垂直居中。
- 已保存尺寸超出允许范围时，自动限制到合法范围。
- 开机启动的显示效果与普通启动一致。
- 如果上次更新前保存了未完成编辑草稿，启动主面板后自动恢复对应编辑窗口。

### 3.2 窗口尺寸与移动

- 主窗口默认及最小尺寸为 `300×450`。
- 主窗口最大尺寸为 `1000×800`。
- 主窗口可拖动、可调整大小，不提供最大化入口。
- 窗口位置或尺寸变化后约 300ms 保存一次，避免移动过程中频繁写入。
- 窗口恢复时必须落在可见显示器区域内，不能完全出现在屏幕外。
- 多显示器和不同 DPI 下，尺寸、位置和工作区限制保持正确。

### 3.3 自绘标题栏

- 标题栏包含 Q 标识、应用标题、置顶、最小化和关闭按钮。
- 标题文字区域可拖动窗口。
- 置顶按钮显示当前状态，并同步修改所有窗口。
- 最小化按钮最小化当前窗口。
- 关闭按钮和系统关闭事件仅隐藏主面板，不退出应用。
- 核心图标必须稳定显示，不能因系统字体缺字而显示为方框。

## 4. 主工具栏与状态区

- “新建”打开独立编辑窗口。
- “全部删除”在没有便签时不可用。
- 点击“全部删除”先显示不可撤销确认弹层，确认后才删除全部便签和附件。
- “设置”打开设置弹层。
- 检测到新版本时，设置入口显示红点；提示信息包含可用版本。
- 语言入口显示将切换到的目标语言，点击后立即刷新主窗、编辑窗、悬浮球和托盘菜单。
- 主面板底部显示当前便签总数。
- 右下角 Q 按钮把主面板切换为悬浮球。
- 没有便签时显示 Q 标识、空状态说明和新建入口。

## 5. 便签排序与显示

### 5.1 排序

- 置顶便签始终排在普通便签之前。
- 每个分组内部优先采用用户手动排序；顺序相同时，最近更新的便签优先。
- 新便签放到对应置顶分组或普通分组的顶部。
- 修改置顶状态后，便签移动到目标分组顶部。
- 拖动便签可以调整顺序。
- 将便签拖到另一分组的目标便签旁时，便签同时采用目标分组的置顶状态。
- 拖动后的置顶状态和完整顺序必须持久保存。

### 5.2 卡片内容

- 卡片使用便签选择的颜色。
- 置顶便签显示置顶标记，并使用更明确的选中描边。
- 有正文时显示正文。
- 正文为空但包含图片时，显示本地化的“图片便签”占位文案。
- 默认情况下，短文本显示一行，较长文本或包含换行的文本显示两行。
- 卡片底部提供文字高度调整手柄，按 22px 行高逐行调整。
- 最小文字高度等于默认显示高度，最大高度不超过完整正文所需高度。
- 用户调整后的文字高度必须持久保存。
- 卡片最多直接展示 4 张图片缩略图和 3 个文件条目；未展示的附件仍完整保留。

### 5.3 点击复制

- 点击卡片主体复制便签内容。
- 正文非空时复制正文。
- 正文为空时，按附件顺序复制所有附件值，并使用换行连接。
- 复制成功后显示约 1.7 秒的提示。
- 图片缩略图、文件区域、操作按钮、颜色选择器、拖动和高度调整不能触发卡片复制。
- 拖动或调整高度结束后的短时间内抑制误触复制。

### 5.4 卡片操作

- 鼠标悬停卡片时显示操作条。
- 操作条包含：置顶/取消置顶、编辑、改色、复制、删除。
- 鼠标离开操作条时可短暂延迟关闭，保证点击按下和抬起能够完整发生。
- 改色显示 12 色选择器，当前颜色有明确选中状态。
- 点击颜色选择器外部关闭选择器。
- 删除单条便签立即删除该便签及其附件，不额外弹出确认。
- 右键菜单包含：复制、编辑、置顶/取消置顶、删除。
- 操作条和右键菜单中的同名操作必须具有相同行为。

## 6. 独立编辑窗口

### 6.1 窗口行为

- 新建和编辑便签均使用独立窗口，不改变主面板尺寸。
- 编辑窗口默认尺寸为 `520×640`，最小尺寸为 `420×520`。
- 编辑窗口默认位于主面板左侧约 12px，并垂直居中。
- 空间不足时，编辑窗口自动限制在当前显示器工作区内。
- 同时只保留一个编辑窗口。
- 已有编辑窗口时再次新建或编辑，会结束旧编辑会话并打开新目标。
- 处于悬浮球模式时发起编辑，先恢复完整主面板。
- 窗口标题根据“新建/编辑”和当前语言实时变化。
- 标题栏支持拖动、全局置顶、最小化和关闭。

### 6.2 正文与颜色

- 顶部显示完整 12 色便签色板。
- 当前颜色有明显的选中描边。
- 正文为多行输入，空内容时显示本地化占位文案。
- 正文、颜色和置顶状态变化后，同步更新当前未完成草稿。
- 保存时移除正文首尾空白，正文内部格式保持不变。

### 6.3 添加附件

- “图片”入口允许一次选择多张图片。
- 支持 PNG、JPG/JPEG、GIF、WebP、BMP 和 SVG。
- 通过图片选择器加入的图片以内嵌数据保存，原文件移动后仍可使用。
- 可以输入网络图片 URL、本地图片路径或普通文件路径。
- 按 Enter 或点击“添加”加入输入值。
- `http://` 和 `https://` 识别为网络来源，`data:` 识别为内嵌数据，其他值识别为本地路径。
- 常见图片扩展名和图片 data URL 识别为图片，其他值识别为文件。
- URL 中的查询参数或片段不影响图片扩展名识别。
- 可以将一个或多个本地文件拖入编辑窗口。
- 拖入时，图片路径添加为图片附件，其他路径添加为文件附件。
- 正文输入处于焦点时粘贴剪贴板图片，会将图片添加为内嵌 PNG 附件。
- 剪贴板没有图片时，不拦截普通文本粘贴。

### 6.4 附件管理

- 图片附件显示缩略图，点击缩略图打开图片预览。
- 图片缩略图提供删除入口。
- 文件附件显示文件名；没有可用文件名时显示完整附件值。
- 文件附件提供删除入口。
- 附件较多时，附件区域可以滚动，不挤压保存操作区。
- 删除编辑中的附件只影响当前草稿，保存后才写入便签。

### 6.5 保存与取消

- “置顶”选项切换当前草稿的置顶状态。
- 保存空正文且没有附件时，按取消处理，不创建空便签。
- 保存新便签时生成新记录并放入正确分组。
- 编辑已有便签时保留原创建时间，更新内容、附件、颜色、置顶状态和更新时间。
- 保存成功后关闭编辑窗口、刷新主面板并显示成功提示。
- 保存失败时保留编辑窗口和当前内容，并显示失败提示。
- 取消、关闭按钮或系统关闭事件会丢弃当前普通编辑会话，不弹出未保存确认。
- 取消或成功保存后清除对应草稿恢复记录。
- 安装更新前，如果编辑窗口存在未完成修改，保存恢复草稿；更新重启后自动重新打开。

## 7. 图片预览

- 主面板和编辑窗口使用一致的图片预览行为。
- 预览覆盖当前窗口内容并使用深色遮罩。
- 点击遮罩、关闭按钮或按 Esc 关闭预览。
- 显示当前序号、图片总数和缩放百分比。
- 多图时左右按钮循环切换图片。
- 未放大时，左/右方向键切换图片。
- `[`、PageUp 切换上一张；`]`、PageDown 切换下一张。
- 切换图片后重置为 100% 缩放和居中位置。
- 缩放范围为 50%–600%，每次调整 25%。
- 鼠标滚轮、`+`、`-` 和缩放按钮均可调整缩放。
- `0`、重置按钮或双击图片恢复 100% 和居中位置。
- 放大后可以拖动图片平移。
- 放大后方向键用于平移；左/右方向键不再切换图片。

## 8. 设置

- 设置以居中弹层显示。
- 点击遮罩或关闭按钮关闭设置。
- 点击设置面板内部空白或控件不能误关闭弹层。
- 设置包含：开机启动、导入、导出、检查更新和当前版本。
- 开机启动开关显示当前系统真实状态，而不只依赖上次保存值。
- 修改开机启动后显示成功或失败提示。
- 当前版本可以点击并打开对应版本发布页。
- 有可用更新时，检查更新入口显示红点和提示。

## 9. 导入与导出

### 9.1 导出

- 导出默认文件名为 `q-note_yyyyMMddHHmm.json`。
- 导出内容包含格式版本、导出时间、全部便签、附件和设置。
- 取消保存文件选择时不显示成功提示，也不修改任何数据。
- 导出成功后显示完成提示。

### 9.2 导入

- 导入支持当前格式，也兼容缺少新字段的旧数据。
- 缺失字段使用安全默认值；无效单条便签或附件不会阻止其他有效内容导入。
- 导入会整体替换当前便签和设置，这是唯一允许主动整体替换用户数据的流程。
- 取消文件选择时不修改数据。
- 解析或读取失败时保留原数据并显示失败提示。
- 导入成功后立即刷新便签、排序、语言、窗口置顶、开机启动和托盘标签。

## 10. 更新

- 应用启动后静默检查一次更新。
- 此后每天本地时间 17:00 再检查一次。
- 静默检查没有更新或失败时不打扰用户。
- 手动检查没有更新时显示“暂无更新”；失败时显示失败提示。
- 发现新版本时显示更新确认，内容包括版本、默认更新说明和可选发布说明。
- 当前平台没有可安装程序时，打开对应版本发布页并提示用户手动下载。
- 自动安装前验证下载地址、文件格式、声明大小和 SHA-256 信息是否有效。
- 下载过程显示当前阶段、版本、发布说明、百分比和已下载/总大小。
- 下载和准备阶段允许取消；进入安装阶段后不允许取消。
- 下载过程中持续检查取消状态。
- 下载结束后验证实际大小和 SHA-256；验证失败不得安装。
- 安装前保存主窗口状态、设置和未完成编辑草稿，并确保数据落盘。
- 安装成功后启动新版本并退出当前进程。
- 下载、准备或安装失败时清理更新状态、保留用户数据并显示对应提示。

## 11. 系统托盘

- 应用运行期间托盘图标常驻。
- 左键点击托盘图标显示并激活主面板。
- 处于悬浮球模式时，左键点击托盘先退出悬浮球模式再显示主面板。
- 托盘菜单包含：窗口置顶/取消置顶、切换语言、切换主面板/悬浮球、退出。
- 菜单文字根据当前语言、置顶状态和悬浮球状态实时变化。
- 点击“退出”前保存窗口状态、设置和编辑草稿，并确保便签数据落盘。

## 12. 30px 悬浮球与贴边

### 12.1 切换与恢复

- 主面板右下角 Q 按钮和托盘菜单均可切换到悬浮球。
- 悬浮球尺寸固定为 `30×30`，背景透明、无原生边框，内部显示 Q 标识。
- 切换时保存主窗口尺寸和位置并隐藏主窗口，尽量保留原窗口实例和界面状态。
- 单击悬浮球恢复原主面板并激活窗口。
- 拖动距离未超过 4px 时按点击处理；超过 4px 后按移动处理，不触发恢复。
- 悬浮球右键菜单包含：置顶/取消置顶、切换语言、恢复主界面、退出。

### 12.2 拖动与吸附

- 悬浮球可以拖到当前显示器工作区内任意位置。
- 距离工作区左、右、上、下边缘 28px 内释放时，吸附到最近边缘。
- 未达到吸附阈值时，停留在工作区内的释放位置。
- 吸附状态记录边缘和沿边位置。
- 多显示器环境按悬浮球当前所在显示器计算工作区。
- Windows 上使用任务栏工作区，并正确处理 DPI 和相邻显示器裁剪。

### 12.3 半隐藏与悬停

- 吸附后使用约 130ms 动画向屏幕外移动一半，只保留半圆可见。
- 鼠标进入可见半圆时，悬浮球完整滑出。
- 鼠标离开完整悬浮球后，再次半隐藏。
- 拖动开始前取消正在进行的隐藏或显示动画，并恢复完整可拖区域。
- 从贴边悬浮球恢复主面板后，记录原边缘和位置 5 分钟。
- 5 分钟内再次收起时回到原边缘和位置，并等待约 500ms 后再半隐藏，避免刚出现就从鼠标下移走。

## 13. 反馈、语言与错误状态

- 中文和英文必须覆盖同一组功能、按钮、菜单、标题、占位文案和错误提示。
- 切换语言后无需重启，所有已打开窗口和托盘菜单立即刷新。
- 复制、保存、导入、导出、开机启动和更新相关结果使用短暂提示反馈。
- 普通成功提示约显示 1.7 秒。
- 危险操作使用红色语义；主要确认操作使用统一主按钮语义。
- 禁用、悬停、按下、选中和错误状态必须视觉可区分。
- 弹层、图片预览、颜色选择器和操作条的层级必须正确，不能被后续卡片或底层控件遮挡。

## 14. 数据与兼容性

- 用户数据位于用户主目录下的 `.q-note/q-note.db`。
- Windows 路径为 `C:\Users\<username>\.q-note\q-note.db`；macOS/Linux 为 `~/.q-note/q-note.db`。
- 新数据位置不存在时，允许从旧安装位置复制已有数据库完成首次迁移。
- 必须保留便签正文、颜色、置顶状态、手动顺序、文字高度、附件类型、附件来源、附件值、附件名称和创建/更新时间。
- 必须保留语言、全局置顶、开机启动、窗口尺寸/位置和悬浮球相关设置。
- 启动时主动清理上次异常遗留的悬浮球会话状态，但不删除其他设置。
- 除明确执行单条删除、全部删除或整体导入替换外，不得主动删除用户数据。
- 更换框架或语言时，现有数据库和导入导出数据必须继续可读写，不能要求用户手工迁移。

| 卡片、输入框、主要控件圆角 | 8px |
| 卡片文字行高 | 22px |
| 卡片色板 | 12 个固定浅色 |
| 主窗口 | 默认/最小 `300×450`，最大 `1000×800` |
| 编辑窗口 | 默认 `520×640`，最小 `420×520` |
| 悬浮球 | `30×30` |

- 主面板、编辑窗口、卡片、弹层、图片预览和悬浮球使用统一的间距、圆角、描边、阴影及图标语义。
- 卡片颜色是内容识别的一部分，迁移时不得随意替换或重排色板。
- 窄窗口下工具栏、操作条和状态信息仍必须完整可用。
- 核心操作优先使用稳定图标资源，不依赖不确定的系统字体符号。

## 16. 框架或语言迁移验收

迁移到其他框架或语言时，至少逐项验证以下场景：

- 空数据首次启动、已有数据库启动和旧安装数据迁移。
- 新建纯文本、纯图片、纯文件和混合附件便签。
- 编辑正文、颜色、附件和置顶状态。
- 点击复制、纯附件复制、hover 操作条、右键菜单、改色、删除、拖动排序和文字高度调整。
- 单图和多图预览的按钮、键盘、滚轮、拖拽、双击和关闭行为。
- 编辑窗口的图片选择、URL/路径添加、文件拖入、剪贴板图片粘贴、附件删除、保存和取消。
- 设置弹层、开机启动、导入、导出、全部删除和版本入口。
- 无更新、检查失败、仅发布页、下载取消、校验失败、安装失败和安装成功流程。
- 主窗口隐藏/托盘恢复、全局置顶、语言同步和正常退出。
- 悬浮球点击、拖动、四边吸附、半隐藏、hover、多显示器及恢复往返。
- 更新重启后的未完成编辑草稿恢复。

迁移验收的判断依据是本文件描述的用户行为，而不是上一版的源码结构或实现方式。
