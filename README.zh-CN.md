## 概述

Q Note 是一个贴近鼠标的小型桌面便签应用，适合快速记录和反复复制：保存文本片段、截图、图片 URL、本地路径和参考备注；置顶重要条目；给卡片上色；需要腾出屏幕时收成 30px 悬浮球。

本分支使用 **GPUI** + **gpui-component** 完全重写（替代 Tauri + Vue）。数据仍保存在同一 SQLite 路径 `~/.q-note/q-note.db`。

## 快速开始

```bash
cargo run
```

| 命令                    | 用途         |

| `cargo fmt`             | 格式化       |

## 功能

| 功能       | 说明                                                         |
| ---------- | ------------------------------------------------------------ |
| 紧凑便签板 | 窄黄面板常驻，快速复制常用内容                               |
| 一键复制   | 点击卡片复制文本；纯附件便签复制附件值                       |
| 卡片管理   | 新建、编辑、删除、置顶、改色                                 |
| 独立编辑窗 | 不影响主面板尺寸                                             |
| 图片与文件 | 文件选择、网络 URL、本地路径                                 |
| 悬浮球     | 收成 30px Q 图标，可拖拽并贴边                               |
| 窗口置顶   | 标题栏 / 托盘切换                                            |
| 系统托盘   | 托盘常驻，点击显示主界面                                     |
| 中英切换   | 工具栏切换，本地保存                                         |
| 开机启动   | 设置里开关，默认关闭                                         |
| 持久化     | 便签、附件、颜色、顺序、高度、窗口与语言等写入 SQLite        |
| 导入导出   | JSON 导入导出（导入会整体替换）                              |

## 技术栈

| 领域   | 方案                                      |
| ------ | ----------------------------------------- |
| 桌面 UI | GPUI 0.2 + gpui-component 0.5            |
| 样式   | 自定义 Q Note 主题 + 原有色板             |
| 存储   | SQLite（`rusqlite`）                      |
| 托盘   | `tray-icon`                               |

> crates.io 上的 `gpui-base` 只是空壳占位程序，**不能**用来保样式。本项目通过 `gpui-component` 主题定制 + 手绘壳层/卡片（`#ffd150`）保持原有视觉。

## 数据位置

| ----------- | --------------------------------------- |

| macOS/Linux | `~/.q-note/q-note.db`                   |
