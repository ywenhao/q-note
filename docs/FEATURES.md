# Q Note 功能规格

本文档是 Q Note 当前功能、交互、视觉和数据行为的事实基线，供日常调整、回归检查以及更换框架或编程语言时使用。

本文档只描述“产品应该做什么”，不记录源码文件、模块、类、接口、依赖或框架实现方式。功能或交互细节发生变化时，直接更新对应条目，使本文档始终反映当前有效行为。

## 1. 产品定位

- Q Note 是一个轻量、紧凑、靠近鼠标使用的桌面便签板，范围为 Windows、macOS 和 Linux 桌面；不要求移动端布局。
- 核心使用场景是快速保存和反复复制短文本、截图、图片地址、本地路径及参考资料。
- 主面板适合窄尺寸常驻，也允许放大以浏览更多内容。
- 重要便签可以置顶，便签可以改色、排序和调整文字显示高度。
- 不需要占用屏幕时，主面板可以收成 30px 悬浮球。
- 应用支持中文和英文，两种语言下的功能与信息层级必须一致。

## 2. 全局行为原则

- 用户便签和设置必须持久保存，正常升级、重启、隐藏窗口或切换悬浮球时不得丢失。
- 主窗口关闭后应用继续驻留托盘；只有明确执行“退出”才结束进程。
- 窗口置顶是全局设置，主窗口、编辑窗口和悬浮球同步生效。
- 所有会删除大量数据、替换全部数据或安装更新的操作，都必须给出清晰反馈或确认。
- 控件点击不得穿透到下层操作。例如点击卡片操作按钮时，不能同时触发卡片复制。
- hover 控件在按下到抬起期间必须保持可操作，不能因 hover 状态瞬间丢失而取消点击。
- 网络图片加载不能阻塞窗口交互；加载失败时保留便签和附件数据，不影响其他内容使用。
- 在不支持窗口定位、贴边或原生裁剪的平台上，应安全降级，不得因此导致应用无法启动或数据丢失。

### 全局不变量

- **尺寸单位**：本文尺寸均为逻辑像素，100% 缩放时对应屏幕像素；窗口移动和屏幕工作区使用同一显示器坐标，允许负坐标。DPI 改变时保持逻辑尺寸，不能把物理像素误当逻辑像素。
- **固定色板**：顺序为 `#fff9db`、`#ffe8cc`、`#ffd8a8`、`#d8f5a2`、`#b2f2bb`、`#c5f6fa`、`#d0ebff`、`#dbe4ff`、`#e5dbff`、`#ffdeeb`、`#ffe3e3`、`#f1f3f5`，新便签默认第一色。编辑器和卡片改色必须使用相同顺序。
- **提交后显示**：保存、删除、顺序、改色、文字高度、语言、置顶和设置，均在持久写入成功后改变已保存内容的显示；编辑中的草稿和拖动中的临时高度可以立即预览。失败后恢复原持久状态。
- **共同弹层动效**：设置、删除、更新、预览、改色、卡片操作条、卡片右键菜单、toast，在创建后的下一帧（约 16ms）从透明度 0、向下偏移 6px 变为透明度 1、偏移 0；时长 150ms、ease。关闭从当前值反向过渡，保留节点 150ms。关闭期间同一弹层再次打开时取消销毁并从当前值转向打开；设置关闭期间的重复关闭忽略。原生文件选择器、系统托盘菜单和悬浮球右键菜单使用系统动效。
- **层级**：卡片普通内容 < 卡片置顶标记 < 高度手柄 < 操作条 < 卡片颜色选择器 < 卡片右键菜单 < 设置/删除 < 更新 < 图片预览 < toast。覆盖层只遮住所属窗口，独立编辑窗与主窗互不遮罩；toast 不截获输入。应用内菜单关闭或弹层打开时不把同一次点击传给底层卡片。
- **共享系统菜单**：托盘和悬浮球菜单均为四项、无分隔线：全局置顶状态操作、切换语言、窗口/悬浮球切换、退出。中文置顶操作为“置顶/取消置顶”，英文为“Pin window/Unpin window”；语言项为“切换语言/Switch language”；切换项依据当前模式使用“切换悬浮球/Switch to Q icon”或“切换主界面/Switch to main window”；最后为“退出/Quit”。
- **语言默认值**：系统语言以 zh 开头时默认中文，其余默认英文；两个入口语言按钮分别显示 `en` 和 `zh`。数字、版本号、路径和用户正文不翻译。
- **图标与文字**：图标使用确定的图形描边和 Q 标识，不使用字体字符代替。默认系统无衬线字体，正文正常字重、标题 600；文字不随辅助字体倍率放大破坏固定行高。长按钮文字保持单行，容器换行或限制宽度；正文保留显式换行并按可用宽度自动折行。

## 3. 启动与主窗口

### 3.1 启动

- 每次启动都先显示完整主面板，不恢复上次进程遗留的悬浮球状态。
- 启动时使用已保存的主窗口尺寸。
- 主窗口初始位置位于主屏右侧约 40px，并垂直居中。
- 已保存尺寸超出允许范围时，自动限制到合法范围。
- 开机启动的显示效果与普通启动一致。
- 如果上次更新前保存了未完成编辑草稿，启动主面板后自动恢复对应编辑窗口。
- 设置 JSON 无法解析时，按默认设置处理；已有便签不得因此被删除或阻止启动。
- 便签或设置完全无法读取时，不得停留在启动加载画面。应使用空便签列表和默认设置显示主面板，并显示加载失败提示约 1.7 秒。

验收场景：

- 设置值被改成非法 JSON 后启动，主面板必须出现。已有便签仍显示；语言、置顶、开机启动和窗口状态使用默认值。
- 数据库完全无法打开时，主面板必须出现并显示空列表和约 1.7 秒的加载失败提示，不得无限停留在启动加载画面。

### 3.2 窗口尺寸与移动

- 主窗口默认及最小尺寸为 `300×450`。
- 主窗口最大尺寸为 `1000×800`。
- 主窗口可拖动、可调整大小，不提供最大化入口。
- 窗口位置或尺寸变化后约 300ms 保存一次，避免移动过程中频繁写入。
- 窗口恢复时必须落在可见显示器区域内，不能完全出现在屏幕外。
- 多显示器和不同 DPI 下，尺寸、位置和工作区限制保持正确。

- 不支持绝对位置的桌面合成器可以决定窗口位置和置顶层级；此时保留合法尺寸和常规显示/隐藏/编辑能力，不循环抢夺窗口位置。
- Windows 的主窗、编辑窗边缘内 6px 为原生缩放区；悬浮球不提供缩放区。窗口标题双击不最大化。

### 3.3 自绘标题栏

- 标题栏包含 Q 标识、应用标题、置顶、最小化和关闭按钮。
- 标题文字区域可拖动窗口。
- 置顶按钮显示当前状态，并同步修改所有窗口。
- 最小化按钮最小化当前窗口。
- 关闭按钮和系统关闭事件仅隐藏主面板，不退出应用。
- 核心图标必须稳定显示，不能因系统字体缺字而显示为方框。

验收场景：

- 首次启动显示 300×450 主窗，工作区足够时右边距 40px、垂直居中；拉大超过 1000×800 被限制，缩小不能低于 300×450。
- 移动/缩放后等待 300ms，退出重启保留尺寸，并按启动定位规则显示；从隐藏或悬浮球恢复则保留当前会话位置。
- 打开编辑窗后切换窗口置顶，两个窗口立即同步；关闭主窗后进程继续运行，托盘左击可恢复主窗。

## 4. 主工具栏与状态区

- “新建”打开独立编辑窗口。
- “全部删除”在没有便签时不可用。
- 点击“全部删除”先显示不可撤销确认弹层，确认后才删除全部便签和附件。
- “设置”打开设置弹层。
- 检测到新版本时，设置入口显示红点；提示信息包含可用版本。
- 语言入口显示将切换到的目标语言，点击后立即刷新主窗、编辑窗、悬浮球和托盘菜单。
- 主面板底部显示当前便签总数。
- 右下角 Q 按钮把主面板切换为悬浮球。
- 没有便签时显示 Q 标识、空状态说明和新建入口。

- 主窗 `Ctrl/Cmd+N` 新建；设置、删除、更新或图片预览覆盖主窗时不执行该快捷键。关闭动效结束前仍按覆盖状态处理。

验收场景：

- 空列表下“全部删除”透明度降低且不能执行；空状态新建按钮与工具栏新建打开同一个编辑入口。
- 有多条便签时点全部删除、再点取消或遮罩，条目与附件不变；确认删除后列表变为空状态、总数变为 0。
- 打开设置后点面板内部空白仍保持打开；点遮罩后经过 150ms 消失。

## 5. 便签排序与显示

### 5.1 排序

- 置顶便签始终排在普通便签之前。
- 每个分组内部优先采用用户手动排序；顺序相同时，最近更新的便签优先。
- 新便签放到对应置顶分组或普通分组的顶部。
- 修改置顶状态后，便签移动到目标分组顶部。
- 拖动便签可以调整顺序。
- 将便签拖到另一分组的目标便签旁时，便签同时采用目标分组的置顶状态。
- 拖动后的置顶状态和完整顺序必须持久保存。
- 排序写入失败时，卡片顺序和置顶状态保持写入前的显示，并显示保存失败提示约 1.7 秒。

- 按下卡片正文后，欧氏位移超过 4px 进入拖动，原卡片透明度变为 0.28；释放在目标卡片上半部插入其前，下半部插入其后，释放不在任何其他卡片内不改变顺序。
- 拖动过程中指针进入窗口顶部 90px 或底部 48px 时，每次移动分别向上/下滚动 12px；上限/下限由列表内容决定。结束后 300ms 内不复制。

### 5.2 卡片内容

- 卡片使用便签选择的颜色。
- 置顶便签显示置顶标记，并使用更明确的选中描边。
- 有正文时显示正文。
- 正文为空但包含图片时，显示本地化的“图片便签”占位文案。
- 卡片没有独立的固定默认高度或最小外框高度；外框高度始终由当前可见文字和附件内容计算，不能为了统一卡片高度而在短内容下方保留空白。
- 默认文字高度等于当前卡片宽度下实际换行数与 2 的较小值，再乘以 22px 行高：实际只需一行时显示一行，实际需要两行或更多时默认显示两行。
- 无附件时，卡片外框高度为 `10px 上内边距 + 可见文字高度 + 9px 下内边距`。因此一行纯文本卡片高 41px，两行纯文本卡片高 63px；手动展开到 N 行时高度为 `19 + 22×N` px。
- 图片区、文件区与前一个可见内容区之间各有 8px 垂直间距；图片区高 58px；每个文件条目高 30px，同一文件区内相邻条目间距为 6px。附件出现或移除时，卡片外框按这些内容尺寸同步增减。
- 主窗口宽度变化后立即按新的可用文字宽度重新计算换行数、默认文字高度和卡片外框高度；从两行变成一行时，纯文本卡片必须同步从 63px 收回到 41px。
- 卡片底部提供文字高度调整手柄，按 22px 行高逐行调整。
- 最小文字高度等于当前宽度下的默认显示高度，最大文字高度等于完整正文在当前宽度下的实际总行高；拖动过程中不得越过这两个边界。
- 用户调整后的文字高度必须持久保存。手柄按下记住起始可见行数和指针 Y，拖动行数为 `ceil(起始行数 + Y 位移/22)`，再限制到默认行数与完整行数之间；抬起才提交。指针离开卡片仍继续本次调整，调整结束后 300ms 不触发复制。
- 卡片最多直接展示 4 张图片缩略图和 3 个文件条目；未展示的附件仍完整保留。

验收场景：

- 新建一条在当前宽度下不会换行、且没有附件的便签，卡片外框必须为 41px 高，文字下方不得出现由固定默认高度造成的额外空白。
- 新建一条在当前宽度下需要两行或更多行的纯文本便签，默认只显示两行且卡片外框为 63px 高；超过当前可见行数的正文在末尾显示 `...`。
- 调宽主窗口直到同一条正文由两行变成一行，卡片外框必须同步由 63px 变为 41px；调窄后重新按实际换行数恢复一行或两行默认高度。
- 将文字高度手动展开到完整内容高度后重启应用，展开行数应恢复；若改变窗口宽度使完整正文所需行数减少，恢复高度必须限制到新的完整内容高度，不能留下空白行。

### 5.3 点击复制

- 点击卡片主体复制便签内容。
- 正文非空时复制正文。
- 正文为空时，按附件顺序复制所有附件值，并使用换行连接。
- 复制成功后显示约 1.7 秒的提示。
- 图片缩略图、文件区域、操作按钮、颜色选择器、拖动和高度调整不能触发卡片复制。
- 拖动或调整高度结束后的短时间内抑制误触复制。

### 5.4 卡片操作

- 鼠标悬停卡片时显示操作条。
- 操作条包含：置顶/取消置顶、编辑、改色、复制、删除。
- 鼠标离开操作条时可短暂延迟关闭，保证点击按下和抬起能够完整发生。
- 改色显示 12 色选择器，当前颜色有明确选中状态。
- 点击颜色选择器外部关闭选择器。
- 删除单条便签立即删除该便签及其附件，不额外弹出确认。
- 单条删除或全部删除写入失败时，被删内容仍保持写入前的显示，并显示删除失败提示约 1.7 秒。
- 改色、置顶或文字高度写入失败时，卡片保持写入前的显示，并显示保存失败提示约 1.7 秒。
- 右键菜单包含：复制、编辑、置顶/取消置顶、删除。
- 操作条和右键菜单中的同名操作必须具有相同行为。

- 操作条只有悬停右侧箭头区域或点击箭头后展开。离开卡片/操作条 150ms 后开始关闭；按住操作条期间不关闭。卡片箭头、按钮、图片、文件和高度手柄与正文拖动/复制互斥。
- 改色选择器一次只打开一个，另一次右键或打开设置/删除时关闭；改色后关闭并提交颜色。右键菜单在窗口内距边缘至少 8px，打开另一个右键菜单时替换旧目标；Escape 或点外部关闭。
- 卡片高度变化、排序完成、改色和分组切换不额外播放位移动画；颜色/描边/阴影变化为 160ms，保证拖动时布局立即跟随。

验收场景：

- 卡片正文点击复制全文，显式换行保留；纯文件便签复制各附件完整值并用换行连接，点击文件条本身不复制。
- 在箭头展开后依次点置顶、编辑、复制或删除，同一次按下/抬起只产生指定操作，不额外复制。
- 两条普通便签拖动交换后重启保持顺序；把普通便签放到置顶目标旁，置顶标记与新顺序一起保存。模拟写入失败时两者均保持旧值。
- 改色面板展开后点卡片外部，面板淡出且不复制；打开设置时色板关闭，设置位于所有卡片之上。

## 6. 独立编辑窗口

### 6.1 窗口行为

- 新建和编辑便签均使用独立窗口，不改变主面板尺寸。
- 编辑窗口默认尺寸为 `520×640`，最小尺寸为 `420×520`。
- 编辑窗口最大尺寸为 `1000×800`。
- 编辑窗口默认位于主面板左侧约 12px，并垂直居中。
- 空间不足时，编辑窗口自动限制在当前显示器工作区内。
- 同时只保留一个编辑窗口。
- 已有编辑窗口时再次新建或编辑，会结束旧编辑会话并打开新目标。
- 处于悬浮球模式时发起编辑，先恢复完整主面板。
- 窗口标题根据“新建/编辑”和当前语言实时变化。
- 标题栏支持拖动、全局置顶、最小化和关闭。

### 6.2 正文与颜色

- 顶部显示完整 12 色便签色板。
- 当前颜色有明显的选中描边。
- 正文为多行输入，空内容时显示本地化占位文案。
- 正文、颜色和置顶状态变化后，同步更新当前未完成草稿。
- 保存时移除正文首尾空白，正文内部格式保持不变。

### 6.3 添加附件

- “图片”入口允许一次选择多张图片。
- 支持 PNG、JPG/JPEG、GIF、WebP、BMP 和 SVG。
- 通过图片选择器加入的图片以内嵌数据保存，原文件移动后仍可使用。
- 可以输入网络图片 URL、本地图片路径或普通文件路径。
- 按 Enter 或点击“添加”加入输入值。
- `http://` 和 `https://` 识别为网络来源，`data:` 识别为内嵌数据，其他值识别为本地路径。
- 常见图片扩展名和图片 data URL 识别为图片，其他值识别为文件。
- URL 中的查询参数或片段不影响图片扩展名识别。
- 可以将一个或多个本地文件拖入编辑窗口。
- 拖入时，图片路径添加为图片附件，其他路径添加为文件附件。
- 正文输入处于焦点时粘贴剪贴板图片，会将图片添加为内嵌 PNG 附件。
- 剪贴板没有图片时，不拦截普通文本粘贴。

### 6.4 附件管理

- 图片附件显示缩略图，点击缩略图打开图片预览。
- 图片缩略图提供删除入口。
- 文件附件显示文件名；没有可用文件名时显示完整附件值。
- 文件附件提供删除入口。
- 附件较多时，附件区域可以滚动，不挤压保存操作区。
- 删除编辑中的附件只影响当前草稿，保存后才写入便签。

### 6.5 保存与取消

- “置顶”选项切换当前草稿的置顶状态。
- 保存空正文且没有附件时，按取消处理，不创建空便签。
- 保存新便签时生成新记录并放入正确分组。
- 编辑已有便签时保留原创建时间，更新内容、附件、颜色、置顶状态和更新时间。
- 保存成功后关闭编辑窗口、刷新主面板并显示成功提示。
- 保存失败时保留编辑窗口和当前内容，并显示失败提示约 1.7 秒；主面板在保存成功前不替换对应卡片。
- 取消、关闭按钮或系统关闭事件会丢弃当前普通编辑会话，不弹出未保存确认。
- 取消或成功保存后清除对应草稿恢复记录。
- 安装更新前，如果编辑窗口存在未完成修改，保存恢复草稿；更新重启后自动重新打开。
- `Ctrl/Cmd+S` 保存，连续保存请求只处理一次。普通编辑期间正文、颜色、附件和置顶草稿为会话状态，不逐字写入磁盘；明确退出应用时也保存恢复草稿。正常取消不保存该草稿。
- 每个新编辑会话在约 60ms 后将焦点置于正文，清空附件地址输入框。切换已有/新便签会丢弃上一普通会话；图片选择结果只追加到发起选择时仍存在的会话。
- 图片预览打开后正文和地址输入失焦，关闭动效结束后恢复原输入焦点。预览期间普通打字、保存和粘贴不得更改底层草稿。Tab 的文本输入焦点移动使用系统输入控件行为；全局保存快捷键在正文和地址输入中均可用。
- 地址框空白或全为空格时“添加”和 Enter 不执行操作；同名/同值附件允许重复，移除只删除选中的那一个。媒体地址框粘贴使用文本，不把剪贴板图片追加为附件。
- 网络和本地图片异步加载；失败显示图片占位图标，仍可删除、保存、导出和复制附件值。单个本地图片或网络 SVG 超过 64MiB 时不加载；SVG 按原比例栅格显示，最长边最多 4096px，不更改保存的原始数据。

验收场景：

- 主窗 300×450，新建后独立编辑窗为 520×640，主窗尺寸不变；再打开另一个目标，只有一个编辑窗并显示新目标。
- 输入首尾空格、中间换行，选色并加两个同名附件；保存后正文仅移除首尾空白，附件分别保留。再次编辑删除其中一个并取消，持久附件不变。
- 从选择器加入图片后移动原文件，内嵌图片仍显示；拖入路径后移动原文件，显示失败占位但附件路径仍在。
- 保存全空草稿关闭窗口且不增加便签；保存失败时窗口、正文和附件保持可重试，主面板保持旧卡片。
- 打开图片预览后键入普通文字和 Ctrl/Cmd+S，草稿与主面板均不改变；Escape 关闭预览后恢复输入焦点。

## 7. 图片预览

- 主面板和编辑窗口使用一致的图片预览行为。
- 预览覆盖当前窗口内容并使用深色遮罩。
- 点击遮罩、关闭按钮或按 Esc 关闭预览。
- 显示当前序号、图片总数和缩放百分比。
- 多图时左右按钮循环切换图片。
- 未放大时，左/右方向键切换图片。
- `[`、PageUp 切换上一张；`]`、PageDown 切换下一张。
- 切换图片后重置为 100% 缩放和居中位置。
- 缩放范围为 50%–600%，每次调整 25%。
- 鼠标滚轮、`+`、`-` 和缩放按钮均可调整缩放。
- `0`、重置按钮或双击图片恢复 100% 和居中位置。
- 放大后可以拖动图片平移。
- 放大后方向键用于平移；左/右方向键不再切换图片。

- 图片预览使用“共同弹层动效”。遮罩为 `rgba(24,33,47,0.72)`，覆盖整个所属窗口并裁剪溢出内容。
- 顶部工具胶囊距上/右各 12px，内边距 4px、间距 4px；序号和百分比各最小 42px、字号 10.92px；缩放/重置/关闭按钮 28×28，白色 14px 图标。
- 图片舞台距上 54px、下 42px、左右 44px。100% 为等比适应：不放大超过图片固有尺寸，宽最多 `min(1120, 窗口宽-88)`，高最多 `窗口高-108`，在舞台内居中。图片圆角 8px，阴影 `0 24px 70px rgba(0,0,0,0.38)`。
- 上一/下一按钮只在多图时出现，分别距左/右 12px、垂直居中，命中区 34×46、白色 14px 图标。切换到首/尾时循环；仅有一图时导航键不切换。
- 缩放按钮、键盘 `+`/`=`/`-`、每个滚轮事件调整 25%，限制到 50%–600%；双击判定间隔小于 300ms。方向键每次平移 36px。
- 平移范围：每个轴为 `±(max(0,(适应后尺寸×缩放值-窗口尺寸)/2)+80)`；缩放不超过 100% 时强制居中。手动拖动时位置立即改变，非拖动的缩放/复位/平移为 100ms ease-out。切换、复位和缩小均重新限制平移范围。
- 图片本体不触发遮罩关闭；图片外的舞台空白、其他遮罩区域可以关闭。加载失败时保留预览工具和关闭能力，不删除附件。

验收场景：

- 两张图片中先点第一张，显示 `1 / 2`、100%；左键导航循环到 `2 / 2`，缩放/位移归零。
- 连续缩小到 50%、放大到 600%，再操作不越界；100% 按方向键换图，125% 按方向键每次平移 36px。
- 放大并拖到边界，平移被限制；按 0 或双击回到 100% 居中。点击图像不关闭，点击外部或 Escape 后 150ms 消失。

## 8. 设置

- 设置以居中弹层显示。
- 设置标题保持水平居中，关闭按钮固定在面板右上角。
- 点击遮罩或关闭按钮关闭设置。
- 点击设置面板内部空白或控件不能误关闭弹层。
- 设置包含：开机启动、导入、导出、检查更新和当前版本。
- 开机启动开关显示当前系统真实状态，而不只依赖上次保存值。
- 修改开机启动后显示成功或失败提示。
- 语言、置顶和开机启动写入成功后才更新对应界面状态；写入失败时界面保持原值。
- 窗口置顶必须先写入成功，再同步到主窗口、编辑窗口和悬浮球；写入失败时所有窗口保持原来的置顶状态，并显示保存失败提示约 1.7 秒。
- 当前版本可以点击并打开对应版本发布页。
- 有可用更新时，检查更新入口显示红点和提示。

- 开机启动开关提交过程中禁用重复操作；更新检查进行中检查入口禁用并显示“检查更新中/Checking for updates”。开关系统操作成功、持久设置写入失败时回退系统注册；再次打开设置重新读取系统状态。
- Escape 关闭设置；确认更新、进度或图片预览位于设置之上时，Escape 优先处理最上层。

验收场景：

- 系统中手动改变开机启动后再打开设置，开关显示系统实际值；快速连点不会发起相互覆盖的系统注册。
- 点击当前版本打开对应发布页；检查过程中入口禁用，无新版本/失败分别显示对应提示；发现版本后入口红点与主工具栏同步。

## 9. 导入与导出

### 9.1 导出

- 导出默认文件名为 `q-note_yyyyMMddHHmm.json`。
- 导出内容包含格式版本、导出时间、全部便签、附件和设置。
- 取消保存文件选择时不显示成功提示，也不修改任何数据。
- 导出成功后显示完成提示。

### 9.2 导入

- 导入支持当前格式，也兼容缺少新字段的旧数据。
- 缺失字段使用安全默认值；无效单条便签或附件不会阻止其他有效内容导入。
- 导入会整体替换当前便签和设置，这是唯一允许主动整体替换用户数据的流程。
- 取消文件选择时不修改数据。
- 解析或读取失败时保留原数据并显示失败提示。
- 解析成功但写入替换失败时，磁盘和界面都保持导入前的数据，并显示导入失败提示。
- 导入替换必须一次性生效：中途失败不得留下空库或半导入结果。
- 导入成功后立即刷新便签、排序、语言、窗口置顶、开机启动和托盘标签；关闭当前编辑会话与编辑窗，防止旧草稿覆盖新数据。系统拒绝导入的开机启动值时，显示开机启动失败，并将开关同步回系统实际状态，便签导入仍保留。
- 非对象的单条便签、非对象或缺少字符串值的附件跳过；对象便签缺正文默认空、缺颜色默认第一色、缺置顶默认否、缺更新时间用导入时间、缺创建时间用更新时间、缺顺序用负的更新时间、缺手动高度用默认高度。
- 缺少标识生成新标识；重复便签标识和全局重复附件标识分别重新生成，内容、附件顺序和重复名称均保留。缺少附件类型根据图片扩展名/图片内嵌值推断；未知来源兼容为网络来源。导入格式版本不匹配不单独拒绝可兼容内容。

验收场景：

- 选择非法 JSON 或取消文件选择时，便签和设置保持不变，取消时不显示成功或失败提示。
- 文件可解析但写入替换中途失败时，原便签和设置仍在，界面不切换到导入内容，并显示导入失败提示。
- 合法文件导入成功后，主面板立即显示导入的便签和设置；再次启动后内容保持导入结果。

## 10. 更新

- 应用启动后静默检查一次更新。
- 此后每天本地时间 17:00 再检查一次。
- 静默检查没有更新或失败时不打扰用户。
- 手动检查没有更新时显示“暂无更新”；失败时显示失败提示。
- 发现新版本时显示更新确认，内容包括版本、默认更新说明和可选发布说明。
- 当前平台没有可安装程序时，打开对应版本发布页并提示用户手动下载。
- 自动安装前验证下载地址、文件格式、声明大小和 SHA-256 信息是否有效。
- 下载过程显示当前阶段、版本、发布说明、百分比和已下载/总大小。
- 下载和准备阶段允许取消；进入安装阶段后不允许取消。
- 下载过程中持续检查取消状态。
- 下载结束后验证实际大小和 SHA-256；验证失败不得安装。
- 安装前保存主窗口状态、设置和未完成编辑草稿，并确保数据落盘。
- 安装成功后启动新版本并退出当前进程。
- 下载、准备或安装失败时清理更新状态、保留用户数据并显示对应提示。

- 更新清单只接受更高的合法语义版本；预发布版本低于同号正式版。原生自动更新资源必须提供 HTTPS 无账户/密码/片段的地址、`binary` 格式、正整数大小和 64 位十六进制 SHA-256；缺少任一项按发布页手动下载处理。
- 下载从 0 字节开始反馈，总大小使用声明大小；超过声明大小立即失败，结束时字节数和摘要都必须匹配。网络连接超时 15 秒、读取超时 5 秒、总请求超时 600 秒。取消后清理临时文件并返回空闲状态，后续可以重新检查/下载。
- 准备阶段等待窗口状态保存确认，最多 5 秒；然后保存当前设置、未完成编辑草稿并完成持久刷盘。任一步失败不进入安装。取消与进入安装的竞争以状态切换先后决定：取消先被接受则不安装，安装已开始则取消不可用。
- 进度条高 7px，浅蓝轨道、蓝色填充，百分比四舍五入并限制 0–100；同时显示已下载/总字节，按 B、KB、MB 格式显示。发布说明在最多 140px 的区域滚动，长内容不挤掉取消/确认按钮。
- 替换后新进程等待旧进程结束，最多 30 秒，避免旧进程仍持有数据库或单实例状态。可执行程序所在位置无写权限时安装失败，不清除便签或草稿。

验收场景：

- 无更新的静默检查无弹层，手动检查显示“暂无更新/No updates”；断网的静默检查不打扰，手动检查显示失败。
- 更新资源缺摘要、大小为 0、格式为归档或地址为 HTTP 时不自动安装，转发布页；合法清单下载校验通过才允许准备。
- 下载中取消或模拟摘要/大小不匹配，不替换程序；准备阶段保存失败不安装，草稿仍可编辑。
- 安装开始后取消按钮禁用；成功重启后便签和窗口尺寸存在，原未完成草稿重新打开，编辑取消后再启动不重复恢复。

## 11. 系统托盘

- 应用运行期间托盘图标常驻。
- 左键点击托盘图标显示并激活主面板。
- 处于悬浮球模式时，左键点击托盘先退出悬浮球模式再显示主面板。
- 托盘菜单遵守“共享系统菜单”。
- 菜单文字根据当前语言、置顶状态和悬浮球状态实时变化。
- 点击“退出”前保存窗口状态、设置和编辑草稿，并确保便签数据落盘。

- Linux 桌面没有托盘宿主时，主窗仍可使用；再次启动应用激活现有进程的完整主面板。托盘不可用不阻止启动和保存。

验收场景：

- 完整主窗关闭后托盘左击显示并激活原窗口；悬浮球模式下左击托盘先隐藏球再显示主窗。
- 从托盘切换语言和置顶后，打开球右键菜单，相同状态下四项文字、顺序、分隔方式完全一致。
- 有未保存草稿时从托盘退出，重启恢复该草稿；退出保存失败时进程保留并显示失败提示。

## 12. 30px 悬浮球与贴边

### 12.1 切换与恢复

- 主面板右下角 Q 按钮和托盘菜单均可切换到悬浮球。
- 悬浮球尺寸固定为 `30×30`，背景透明、无原生边框，内部显示 Q 标识。
- 悬浮球出现后下一帧从透明度 0 到 1，180ms 淡入；切回主面板立即隐藏球，不等待淡出。
- 切换时保存主窗口尺寸和位置并隐藏主窗口，尽量保留原窗口实例和界面状态。
- 单击悬浮球恢复原主面板并激活窗口。
- 拖动距离未超过 4px 时按点击处理；超过 4px 后按移动处理，不触发恢复。
- 悬浮球右键菜单包含：置顶/取消置顶、切换语言、恢复主界面、退出。
- 悬浮球右键菜单与系统托盘右键菜单遵守“共享系统菜单”。

### 12.2 拖动与吸附

- 悬浮球可以拖到当前显示器工作区内任意位置。
- 距离工作区左、右、上、下边缘 28px 内释放时，吸附到最近边缘。
- 未达到吸附阈值时，停留在工作区内的释放位置。
- 吸附状态记录边缘和沿边位置。
- 多显示器环境按悬浮球当前所在显示器计算工作区。
- Windows 上使用任务栏工作区，并正确处理 DPI 和相邻显示器裁剪。

### 12.3 半隐藏与悬停

- 吸附后使用约 130ms 动画向屏幕外移动一半，只保留半圆可见。
- 鼠标进入可见半圆时，悬浮球完整滑出。
- 鼠标离开完整悬浮球后，立即以 130ms 动画再次半隐藏。
- 拖动开始前取消正在进行的隐藏或显示动画，并恢复完整可拖区域。
- 从贴边悬浮球恢复主面板后，记录原边缘和位置 5 分钟。
- 5 分钟内再次收起时回到原边缘和位置，并等待约 500ms 后再半隐藏，避免刚出现就从鼠标下移走。

- 130ms 滑动使用 ease-out-cubic：从当前坐标到目标坐标，进度为 `1-(1-t)^3`；再次 hover/leave 从当前帧反转，不跳到旧起点。左右边分别水平移出 15px，上下边分别垂直移出 15px。释放后的初次隐藏也等待 500ms。
- 贴边时可见/可点击区域为 30px 圆与所属工作区的交集；移出的半圆不能出现在相邻显示器，也不能截获该显示器点击。展开后完整圆可用，圆角外透明区域不接收点击；不支持原生形状裁剪的环境保留可启动、可恢复能力。
- 恢复位置只在本次进程内保留 5 分钟；未使用过球时不能把默认原点当成已保留位置。显示器移除或工作区变化时，下一次收起把球限制在现有工作区；失去原边缘时取消原贴边状态。

验收场景：

- 应用启动后先多次新建/取消，再第一次收起；球位于主窗右下角对应位置，不出现在屏幕原点。
- 释放在距右边 28px 处吸附，29px 处不吸附；负坐标显示器使用同样阈值。拖动超过 4px 不恢复主窗。
- 吸附右边等待 500ms，再经过 130ms，仅 15px 半圆可见；指针进入半圆后 130ms 内回到完整圆，离开后反向滑回。
- 从贴边球恢复主窗，5 分钟内再收起回到原位置并延迟 500ms 隐藏；超过 5 分钟按当前主窗右下角重新计算。
- 两个相邻显示器之间贴边时，另一显示器不显示移出部分，也不被透明/隐藏区域挡住。

## 13. 反馈、语言与错误状态

- 中文和英文必须覆盖同一组功能、按钮、菜单、标题、占位文案和错误提示。
- 切换语言后无需重启，所有已打开窗口和托盘菜单立即刷新。
- 复制、保存、导入、导出、开机启动、加载失败、删除失败和更新相关结果使用短暂提示反馈。
- 普通成功提示约显示 1.7 秒。
- 危险操作使用红色语义；主要确认操作使用统一主按钮语义。
- 禁用、悬停、按下、选中和错误状态必须视觉可区分。
- 弹层、图片预览、颜色选择器和操作条的层级必须正确，不能被后续卡片或底层控件遮挡。
- 设置、删除确认、更新确认、更新进度、颜色选择器、toast 和图片预览等应用内弹层，打开时统一淡入并轻微上移，关闭时反向淡出，动画时长约 140–160ms。

## 14. 数据与兼容性

- 用户数据位于用户主目录下的 `.q-note/q-note.db`。
- Windows 路径为 `C:\Users\<username>\.q-note\q-note.db`；macOS/Linux 为 `~/.q-note/q-note.db`。
- 新数据文件尚不存在时，启动过程必须先从旧安装位置复制数据库，然后再打开或创建新位置的数据库。不得先创建空的新数据库再检查旧文件，否则复制不会发生。
- Windows 旧位置为 `%APPDATA%\com.win11.q-note\q-note.db`。若该文件存在且新文件尚不存在，复制到 `C:\Users\<username>\.q-note\q-note.db`，不删除旧文件。
- 新文件已经存在时（即使尚未写入便签）不得用旧文件覆盖。
- 必须保留便签正文、颜色、置顶状态、手动顺序、文字高度、附件类型、附件来源、附件值、附件名称和创建/更新时间。
- 必须保留语言、全局置顶、开机启动、窗口尺寸/位置和悬浮球相关设置。
- 启动时主动清理上次异常遗留的悬浮球会话状态，但不删除其他设置。
- 除明确执行单条删除、全部删除或整体导入替换外，不得主动删除用户数据。
- 更换框架或语言时，现有数据库和导入导出数据必须继续可读写，不能要求用户手工迁移。

## 16. 框架或语言迁移验收

迁移到其他框架或语言时，至少逐项验证以下场景：

- 空数据首次启动、已有数据库启动和旧安装数据迁移。
- 新建纯文本、纯图片、纯文件和混合附件便签。
- 编辑正文、颜色、附件和置顶状态。
- 点击复制、纯附件复制、hover 操作条、右键菜单、改色、删除、拖动排序和文字高度调整。
- 单图和多图预览的按钮、键盘、滚轮、拖拽、双击和关闭行为。
- 编辑窗口的图片选择、URL/路径添加、文件拖入、剪贴板图片粘贴、附件删除、保存和取消。
- 设置弹层、开机启动、导入、导出、全部删除和版本入口。
- 无更新、检查失败、仅发布页、下载取消、校验失败、安装失败和安装成功流程。
- 主窗口隐藏/托盘恢复、全局置顶、语言同步和正常退出。
- 悬浮球点击、拖动、四边吸附、半隐藏、hover、多显示器及恢复往返。
- 更新重启后的未完成编辑草稿恢复。

迁移验收的判断依据是本文件描述的用户行为，而不是上一版的源码结构或实现方式。
