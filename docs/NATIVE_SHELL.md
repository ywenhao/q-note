# Native Shell 实现与验证

本分支使用 Longbridge Native Shell 0.1.1，固定源码提交 `85be2a2e34ab4879acfa74bde3c5bbdc3cc737d0`。产品行为以 [FEATURES.md](./FEATURES.md) 为准。本文件只记录实现与验证，不替代功能规格。

## 结构

- `ui`：主面板、独立编辑窗、悬浮球三个 TSX 入口。使用 NSH 原生 View/Text/Input/Scroll/Image、signals、Canvas；没有浏览器 DOM 或 WebView。Lucide 图形路径以 Canvas 描边，Q 图标使用内嵌 PNG。
- `native`：共享状态、兼容 SQLite 仓库、附件、剪贴板、开机启动、导入导出、更新。数据提交成功后更新快照。每个窗口有独立脚本引擎，按版本获取共享数据及窗口专属输入事件。
- `desktop`：GTK 4、AppKit、Win32 原生宿主，负责托盘、独立窗口、工作区、置顶、关闭驻留、文件拖入和悬浮球裁剪。UI 包在编译时嵌入程序，更新可执行文件即包含界面更新。
- `scripts/native-shell.mjs`：固定 CLI 和源码下载、校验 CLI SHA-256、生成类型、构建三个入口、开发重建、release 编译。SDK 编译缓存位于根 target 下，以便一次 cargo clean 清理。
- `scripts/package.mjs` / `scripts/updater.mjs`：便携包、macOS 应用目录、可执行程序更新及摘要/大小清单生成。发布工作流在所有平台打包成功后统一发布，避免半成品成为新版本。

持久数据不依赖 NSH 的状态机制。数据库表、字段名和 JSON 格式兼容旧版；首次旧库迁移使用只读 SQLite 备份，包含 WAL 数据，目标存在时绝不覆盖。测试通过 `Q_NOTE_DATA_DIR` 或显式临时路径隔离个人数据库。

附件列表按持久 ID 保留控件，避免快照更新打断图片加载或按钮按下/抬起。路径图片与 SVG 在工作线程读取/转换；原始附件值不变。网络加载失败只影响显示。卡片行数使用真实文字排版结果，窗口宽度变化立即重新计算 41px/63px 或展开高度。

## 已执行验证

2026-10-20，在 Linux/WSL 环境完成：

- 三个 NSH 入口类型检查、格式检查和 Rust workspace 检查。
- Linux release 可执行程序编译、便携归档与更新清单生成；从最终便携包启动同一套真实窗口回归并通过。测试和检查命令会先生成所需 UI 包，可用于新检出的项目。
- 16 项 Rust 测试：数据库/JSON 全字段往返、旧表结构、损坏设置、重复标识/名称、写入失败回滚、排序/删除/草稿原子性、含 WAL 的旧库迁移与不覆盖、跨置顶分组排序、28px 吸附边界及负坐标、首次收起位置与跨主窗显示器切换的5分钟位置保留、SVG 渲染、本地17:00调度、更新元数据拒绝与下载截断/超长/损坏/取消。
- Node 发布清单测试：平台地址映射，以及无效大小、摘要、路径、格式和平台拒绝，发布文件实际大小/摘要与元数据一致性。
- 真实 GTK 窗口在独立 Xvfb/Openbox/D-Bus 会话中回归：新建、键盘输入/保存、剪贴板、独立编辑窗取消、右键和操作条置顶/取消、色板改色、拖动排序与卡片外释放不重排、拖出卡片边界调整高度、主窗缩放、路径图片缩略图、预览/滚轮缩放/Escape及关闭期间新建快捷键隔离、设置外部关闭、中英文及编辑窗标题同步、预览期间输入/保存隔离、30px 悬浮球拖动/贴边半隐藏/悬停展开/恢复、主窗关闭驻留和二次启动激活。
- 截图像素断言验证：窄窗纯文本卡片分别为 63px 和 41px；拉宽后同一长文本卡片收回 41px；手动高度与持久行高对应；图片预览遮罩实际出现且缩放改变图片覆盖范围。
- Windows x64 GNU 和 macOS ARM64 交叉编译检查，包括原生宿主、托盘、输入、悬浮球和更新代码。

`tests/native-smoke.py` 启动后等待首帧及编辑会话切换，不向尚未挂载的输入区发送测试按键。所有示例内容写入临时数据库；截图/日志输出到 `dist/smoke`。README 截图来自该原生程序。

## 验证边界

本地没有 Windows/macOS 桌面会话，因此交叉编译结果不能代替这两个系统的交互实测；多显示器不同 DPI、原生托盘弹出与 macOS 图层裁剪仍应在对应桌面执行回归。CI 对 Windows、Linux、Apple Silicon macOS 和 Intel macOS 分别运行实际主机构建及数据测试，Linux 另运行真实窗口回归。

WSL 的测试桌面没有 StatusNotifierWatcher，程序确认托盘不可用时仍可保存/隐藏，并可通过再次启动恢复。实际桌面托盘、系统开机启动注册、交互式文件选择器、外部文件拖入与系统图片剪贴板需要相应桌面服务。数据处理和回滚已由隔离仓库测试覆盖。

未向公开 Release 上传测试版本，也未替换正在使用的应用执行完整更新安装。下载流、元数据、校验与取消通过隔离测试；最终安装/重启和系统权限失败路径需要发布候选包在相应系统验证。

## 构建环境

Linux 使用 GTK 4 开发包和 libclang，不再需要 WebKit、Tauri 或 JavaScript UI 运行时。开发入口为 `pnpm dev`，发布入口为 `pnpm build`，打包为 `pnpm package`。直接 cargo build 前必须先 `pnpm build:ui`，否则构建脚本会明确拒绝缺失 UI 包。

默认 NSH CLI 使用官方发布二进制，源码固定到上述提交。Intel macOS 从源码构建 CLI；需要 `gh` 认证或 GH_TOKEN。`NSH_BIN` 和 `NSH_SOURCE` 可用于已有的匹配工具链。Rust 依赖由根 Cargo.lock 固定；pnpm 仅管理开发、格式和版本发布工具。
